# Estimote Inc

> Estimote, Inc. (founded 2012, New York City & Kraków) builds location and proximity
> sensors using Bluetooth Low Energy, Ultra Wideband (UWB), and LTE-M / NB-IoT. Its
> UWB Tags are programmable in JavaScript and push events to the cloud over LTE. The
> Estimote Cloud RESTful API manages device fleets, attachments, and LTE Beacon events,
> secured with OAuth 2.0.

## APIs

- [Estimote Cloud API](https://cloud.estimote.com/docs/): REST API for devices, attachments, fleet settings, and LTE Beacon event history. Base URL https://cloud.estimote.com/v1
